# Método de Cramer (2×2)

Programa en Python que resuelve sistemas de ecuaciones lineales 2×2 
mediante la Regla de Cramer, con menú interactivo en consola.

## Estructura

- `funciones_auxiliares.py` — Cálculo de determinantes y de x, y.
- `main.py` — Menú principal y flujo del programa.

## Uso

```bash
python3 main.py
```
